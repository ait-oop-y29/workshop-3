# Воркшоп 3 – Поведенческие паттерны

На данном воркшопе мы проведём рефакторинг минималистичного Web IDE с vim-подобным редактором и git-подобной системой
контроля версий.

## Описание: vim-подобный редактор

- Редактор имеет 3 режима: NORMAL, VISUAL, INSERT
    - NORMAL: используется для навигации по коду, `HJKL` навигация
    - VISUAL: используется для выделения текста, аналогичная навигация; переход из NORMAL через нажатие `V`, выход в
      NORMAL через нажатие `ESC`
    - INSERT: режим редактирования текста, навигация через стрелки; переход из NORMAL через нажатие `I`, выход в NORMAL
      через нажатие `ESC`
- HJKL навигация
    - H - влево
    - J – вниз
    - K – вверх
    - L – вправо

## Описание: git-подобная система контроля версий

- Существует object storage
    - key-value хранилище файлов
    - ключ – хеш файла
- Существует хранилище коммитов
    - отдельный коммит представлен JSON документом, где есть информация о его хеше, хеше родителя, наборе файлов и их
      хешей

## Ограничения

- Редактор поддерживает простую навигацию по тексту и его редактирование.
- Редактор не поддерживает создание новых файлов/директорий, для демо используется mock-файловая система.
- Система контроля версий работает с одной веткой, позволяет смотреть diff её коммитов, позволяет откатываться к
  определённому коммиту.
- Состояние существует только в памяти, при перезапуске приложения – чистый лист.

## Открытые задания (для желающих)

Здесь описан набор маленьких заданий/фич, которые можно реализовать для практики работы с кодовой базой, использующей
поведенческие паттерны. Они могут помочь лучше понять механики использования поведенческих паттернов в более простой
среде (тут уже написано много кода, выстроен базовый каркас приложения, не нужно проектировать решение с нуля).

Эти задания сугубо опциональны, они не оцениваются дополнительными баллами.

Инварианты:

- vim-команды не должны применяться в INSERT режиме
- если команда начала выполняться в определённом режиме, то после её выполнения он не должен сбрасываться

### Уровень "Простой".

- Реализовать команду `a`
    - Аналогично `i`, переходит в режим INSERT, но указатель ставится не перед текущим символом, а после него
- Реализовать команды `w`, `b`, `e`
    - `w` - указатель передвигается к началу ближайшего слова, может перемещаться между строками
    - `b` - указатель передвигается к началу предыдущего слова (если находится внутри какого-то слова – к его началу),
      может перемещаться между строками
    - `e` - указатель передвигается к концу ближайшего слова (если находится внутри какого-то слова – к его концу),
      может перемещаться между строками
- Реализовать команду `.`
    - Нажатие на точку, повторяет последнюю выполненную команду

### Уровень "Средний"

- Реализовать команду `/`
    - По сути – поиск
    - После нажатия `/`, редактор запоминает все далее введённые символы пока не будет введён Enter/Return
    - После ввода, редактор ищет ближайшее место в документе, содержащее введённую последовательность символов
    - Если последовательность – найдена, передвигает к ней указатель
- Реализовать команды `y` и `p`
    - `y` – yank, по сути копирование во внутренний буфер редактора
    - `p` – paste, вставка текста из внутреннего буфера на текущую позицию

### Уровень "Сложный"

- Реализовать комбинации команд редактирования
    - Состоит по сути из 3 команд – `{действие}{вид селектора}{селектор}`
    - Действия
        - `d` – delete, итог - удаление выбранного текста
        - `c` – change, итог – удаление выбранного текста и переход в INSERT режим
        - `v` – visual, итоге – выбранный текст выделяется и редактор переходит в VISUAL режим
    - Вид селектора
        - `i` – in, выбирает текст внутри селектора
        - `a` – around, выбирает текст вокруг селектора, те включая символы селектора
    - Селектор
        - `w` – word, при виде `i` – выбирается только текст слова, при виде `a` выбирается текст слова и пробел после
          него (если есть)
        - символы `"`, `{`/`}`, `(`/`)` – при виде `i` выбирается текст внутри этих символов, при виде `a` выбирается
          текст и сами символы.
    - Примеры:
        - `diw`
        - `ci(`/`ci"`
        - `vi{`
    - Необходимо обрабатывать случи, когда существуют вложенные селекторы (например, пара фигурных скобок внутри пары
      фигурных скобок)
